# 중소기업 지원사업 정보조회 (웹)

중소벤처기업연구원(KOSI) 정책평가팀 · 내부 조회용

**로그인한 사람만** 볼 수 있습니다. 이 저장소에는 화면 파일만 있고 자료는 들어 있지 않습니다 —
사업·공고 자료는 Supabase 에 있고, 로그인하지 않으면 한 줄도 읽히지 않습니다(RLS).

## 조회할 수 있는 것

| 탭 | 내용 |
|---|---|
| 세부사업 | 중앙부처·지자체 세부사업 (2023~2026년) |
| 내역사업 | 내역사업 단위 |
| 공고정보 | 기업마당 공고 |
| 전부처 재정사업 | 중소기업 지원사업 밖의 중앙부처 재정사업 |

예산서 원문(📄)은 중앙부처 **2024~2026년**만 제공합니다.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 화면 전부 (외부 라이브러리를 쓰지 않습니다) |
| `config.js` | Supabase 주소와 publishable 키 — **공개되어도 되는 값**입니다 |

`config.js` 의 키는 브라우저에 실려야 동작하는 공개용 키입니다. 접근 통제는 서버 쪽 RLS 정책이 합니다.

## 고칠 때

이 폴더를 직접 고치지 마십시오. 원본은 `웹앱\` 이고, `python deploy_webapp.py` 가 여기로 복사해 올립니다.
