# 지자체 예산서 수집 작업 지침 (서브에이전트용)

대상 지자체마다 홈페이지 예산 게시판에서 **2024·2025·2026년** 예산 문서 게시물을 찾아 기록하고, **2026년** 문서 첨부파일을 내려받는다.

## 찾을 문서 (연도마다)
- **본예산**: 확정된 "OOOO년도 예산서"(세입세출예산서). 예산안(의회 제출안)과 확정 예산서가 둘 다 있으면 확정본을 우선하되 둘 다 기록해도 된다(구분 뒤 비고에 '예산안' 표시).
- **기금운용계획**: "기금운용계획(서)". 본예산서 파일 안에 합본된 경우가 많다 — 별도 게시물이 없으면 본예산 게시물 비고에 "기금운용계획 합본" 또는 "별도 게시물 없음"을 적는다. 기금운용계획 변경안(추경 시)은 추경 쪽에 기록.
- **추경**: 제1회·제2회… 추가경정예산서. 회차별로 각각 한 줄.

## 방법
- 작업 디렉터리: /home/user/biz_info/지자체예산서
- 네트워크: *.go.kr 접속 가능. curl/python requests 사용 (브라우저 UA 헤더를 붙일 것. CA는 환경변수로 이미 설정됨 — TLS 검증 끄지 말 것). JS로만 렌더링되는 게시판은 Playwright(크로미움 /opt/pw-browsers, 설치 금지)로 열 수 있다.
- 예산 게시판 위치 예: "정보공개 > 예산·재정 > 예산서", "재정공시", "구정/시정 > 예산" 등. 사이트 검색, 사이트맵, WebSearch("OO구 2025년 예산서" 등)로 찾는다. 게시판이 연도별 메뉴로 나뉘어 있을 수 있다.
- 홈페이지에 없고 다른 곳(예: 지방재정365, 열린재정, 의회)에만 있으면 그 주소를 기록하고 비고에 출처를 적는다.
- 등록일은 게시물 목록/상세의 등록(작성)일을 YYYY-MM-DD로. 확인 못 하면 null + 비고.
- **다운로드는 2026년 문서(본예산·기금운용계획·추경)만.** 저장 위치: files/2026/{시도}_{지자체}/ 원래 파일명 유지(파일명이 깨지면 의미 있는 이름으로). 내려받은 뒤 크기가 0이거나 HTML 오류 페이지가 아닌지 확인(`file` 명령). 분할 첨부(여러 권)면 전부 받는다. zip은 풀지 말 것.
- 2024·2025년 문서는 받지 말고 게시물 URL·등록일·첨부파일명만 기록.
- 추측으로 채우지 말 것. 실제 확인한 것만 기록하고 못 찾은 항목은 "미확인"으로 비고에 이유를 적는다.

## 출력 (지자체마다 하나): data/{시도}_{지자체}.json
```json
{
  "시도": "서울특별시", "지자체": "강남구", "홈페이지": "https://www.gangnam.go.kr",
  "게시판": [{"이름": "예산서", "URL": "https://... (목록 페이지 주소)"}],
  "게시물": [
    {"연도": 2026, "구분": "본예산", "회차": null, "제목": "2026년도 강남구 예산서",
     "게시판URL": "https://...list...", "게시물URL": "https://...view...", "등록일": "2026-01-13",
     "첨부파일": [{"파일명": "...pdf", "다운로드URL": "https://...", "크기": 12345678, "저장경로": "files/2026/서울특별시_강남구/...pdf"}],
     "비고": "기금운용계획 합본"}
  ],
  "비고": "지자체 전체에 대한 메모"
}
```
- 구분: "본예산" | "기금운용계획" | "추경". 회차: 추경이면 1,2,…; 아니면 null.
- 2024·2025년 첨부파일은 저장경로 null, 크기 알면 기록.
- JSON은 UTF-8, ensure_ascii=False, indent=2.

마지막에 지자체별로 찾은/못 찾은 항목을 짧게 요약해서 보고할 것.
